# Search basics

A search engine collects documents, builds an index, and ranks pages that match a user's query. A local search tool can index text and Markdown files without uploading them to a remote service.

BM25 is a traditional ranking method. It considers how often query terms appear in a document, how rare those terms are across the collection, and the length of each document.

An extractive summary selects useful sentences from a matching document. It does not generate new facts or replace careful reading of the original source.

Supervised learning-to-rank uses examples labeled as relevant or not relevant. Search quality depends on representative feedback and evaluation, not only on the number of model parameters.
